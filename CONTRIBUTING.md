# Contributing

This project is in foundation/bootstrap phase. Please target small pull requests against `main`, include clear test evidence, identify third-party notices, and do not force-push project history. For the Firestorm source import, use `feature/firestorm-source-import` and retain upstream ancestry and copyrights.

Before claiming a feature complete, provide reproducible build steps, platform, exact SHA, test matrix and fallback behavior. Inworld assets, private tokens, passwords, logs with bearer tokens and personal data must not be committed.

Code should retain applicable LGPL-2.1 and per-file notices. Graphic branding has different rights; see `branding/ASSET_LICENSE.md`.

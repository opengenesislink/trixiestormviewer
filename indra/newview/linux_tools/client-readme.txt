TrixieStorm Viewer — Linux x86_64
================================

TrixieStorm Viewer is a custom Firestorm-derived OpenSimulator client for Stadt NexVerse.
The official supported targets are Generation 1 (hg.stadt-nexverse.de) and,
after activation, Generation 2 beta (beta.stadt-nexverse.de).
Other grid logins are outside this application's product policy.

To start this packaged version from its installation directory:
    ./trixiestormviewer

For the user-specific desktop entry run:
    ./etc/refresh_desktop_app_entry.sh

Do not run bin/do-not-directly-run-trixiestorm-bin directly; the launcher sets
library paths and other runtime environment requirements.

User profiles/settings and logs are separate from the original Firestorm
installation. They must be validated on a real Linux ReleaseOS build.
The original Firestorm and Second Life source attributions/licenses remain
part of this product; consult the included license and notice files.

2. Preserve every original per-file SPDX/copyright/license notice, Firestorm and Linden Lab attribution and applicable copyright/trademark references when importing or modifying upstream files.

4. Source code and modification notices must be supplied in the form required by applicable licenses when distributing binaries. Rebuild/relink requirements and delivery mechanism must be evaluated for each build.
